# قهوتنا — منيو إلكتروني + لوحة تحكم

## اللينكات بعد الرفع
- المنيو للزباين: `https://اسم-حسابك.github.io/اسم-المشروع/`
- لوحة التحكم: نفس اللينك + `#/admin`
- QR لكل ترابيزة: نفس لينك المنيو + `?table=1` ثم `?table=2` وهكذا (بيفتح المنيو بس).

## الفكرة ببساطة
الموقع بيترفع على GitHub Pages (مجاني)، وكل البيانات (الأقسام، الأصناف، الصور، تسجيل الدخول) على Supabase (مجاني). أي تعديل من لوحة التحكم بيظهر فورًا على المنيو من غير ما ترفع حاجة تاني.

## 1) إنشاء مشروع Supabase
1. ادخل على supabase.com واعمل حساب (Sign up).
2. اضغط New project، واكتب اسم (مثلًا qahwatna)، واختار كلمة سر قوية للداتابيز واحتفظ بيها، واختار أقرب منطقة (Region).
3. استنى حوالي دقيقتين لحد ما يخلص.

## 2) تشغيل ملف SQL
1. من القائمة الجانبية: SQL Editor ثم New query.
2. افتح ملف `supabase/setup.sql` من الملف المضغوط، انسخ كل اللي فيه، والصقه، واضغط Run.
3. لازم تظهر رسالة Success. الملف ده بيعمل الجداول والحماية والأقسام الثلاثة وبوكس الصور.

## 3) حساب الأدمن
1. Authentication ثم Users ثم Add user ثم Create new user. اكتب إيميلك وكلمة سر قوية وفعّل Auto Confirm User.
2. Authentication ثم Sign In / Providers: اقفل Allow new users to sign up عشان محدش غيرك يسجّل.
3. SQL Editor ثم New query: افتح `supabase/make_admin.sql`، غيّر الإيميل لإيميلك، وRun. من غير الخطوة دي لوحة التحكم هترفض تفتحلك.

## 4) بوكس الصور
اتعمل تلقائي من الخطوة 2. اتأكد من Storage: لازم تلاقي بوكس اسمه product-images. الكل يقدر يشوف الصور، لكن الأدمن بس هو اللي يرفع أو يمسح.

## 5) مفاتيح الربط
Project Settings ثم API (أو API Keys). انسخ Project URL ومفتاح anon / publishable. ماتستخدمش مفتاح service_role أبدًا ولا تديه لحد.

## 6) GitHub
1. اعمل حساب على github.com.
2. زر + فوق ثم New repository. اكتب اسم (مثلًا qahwatna)، خليه Public، واضغط Create repository.
3. فك ضغط ملف qahwatna.zip على جهازك.
4. في صفحة الريبو اضغط uploading an existing file، واسحب كل محتويات المجلد جوه (مش المجلد نفسه). لازم مجلد `.github` يترفع كمان (وهو مجلد مخفي؛ لو مش باين على الويندوز فعّل Show hidden files).
5. اضغط Commit changes.
ملحوظة: لو رفع المجلد المخفي صعب من المتصفح، استخدم GitHub Desktop.

## 7) المفاتيح السرية
في الريبو: Settings ثم Secrets and variables ثم Actions ثم New repository secret. اعمل اتنين بالظبط:
- الاسم `VITE_SUPABASE_URL` والقيمة Project URL
- الاسم `VITE_SUPABASE_ANON_KEY` والقيمة مفتاح anon

## 8) تشغيل GitHub Pages
1. Settings ثم Pages ثم Source: اختار GitHub Actions.
2. روح تاب Actions، واختار Deploy to GitHub Pages ثم Run workflow (بيشتغل لوحده كمان مع كل رفع).
3. استنى لحد علامة الصح الخضراء (حوالي دقيقتين)، ولينك الموقع بيظهر في Settings ثم Pages.

## 9) الاختبار
1. افتح اللينك: لازم تشوف المنيو بالأقسام الثلاثة (فاضية لحد ما تضيف أصناف).
2. افتح اللينك + `#/admin` وسجّل دخول بإيميلك.
3. من تاب الأصناف اضغط صنف جديد، واكتب الاسم والسعر واختار القسم وارفع صورة، واحفظ.
4. حدّث صفحة المنيو: الصنف لازم يظهر. اضغط "متاح" عشان تخفيه وحدّث تاني.

## لو حصلت مشكلة
- صفحة بيضا أو "مقدرناش نحمّل المنيو": راجع إن السرّين في الخطوة 7 مكتوبين صح، وأعد تشغيل Run workflow.
- الأدمن بيقول "ليس لديه صلاحية": نفّذ make_admin.sql بالإيميل الصح.
- فشل في تاب Actions: ابعتلي نص الخطأ الأحمر.

## تشغيل على جهازك (اختياري)
انسخ `.env.example` باسم `.env` واملاه، ثم `npm install` وبعدين `npm run dev`.
